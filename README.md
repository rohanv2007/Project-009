# Payir

Payir (பயிர் — “crop”) is a bilingual, offline-first season companion for Tamil Nadu farmers. It brings season planning, mandi and MSP prices, crop diagnosis, farm bookkeeping, and government scheme deadlines into one calm tool that works in English or Tamil.

## What it includes

- A season board for Tamil Nadu crop calendars and urgent deadlines
- MSP and mandi price tools, including a quote book and cost-of-production comparison
- A symptom-first Crop Doctor with organic, chemical, and preventive guidance
- A farm ledger for plots, expenses, harvest sales, profit per acre, and break-even prices
- PMFBY, PM-KISAN, and KCC scheme guidance with document and claim checklists
- A practical field guide for planting rates, fertiliser doses, and harvest readiness

All personal farm data stays in the browser through localStorage. No account or backend is required.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
